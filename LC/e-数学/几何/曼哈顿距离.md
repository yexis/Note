##### 2 key points

**曼哈顿转切比雪夫**

$(x,y) \rarr (x + y, x - y)$

> 设 $x \in [1,3000], y \in [1, 3000]$
>
> 则 $x + y \in [1, 6000], x - y \in [-3000, 3000]$
>
> 将$y$轴向上平移，保证所有点位于第一象限，所有点位于$[1,6000]$范围内



**性质**

曼哈顿转切比雪夫后

- 性质1：正方形旋转$45$度
- 性质2：边长变成原来的$\sqrt2$倍
- 性质3：横坐标$x$与纵坐标$y$奇偶性相同（也就是说，只有奇偶性相同的点才可能存在于原正方形）



**曼哈顿距离转切比雪夫的使用场景**

> **场景1**
>
> 曼哈顿转切比雪夫 可以将一个斜着的正方形 转成 正着的正方形，从而正着的正方形更容易进行操作和计算（**比如二维差分**）
>
> 比如原正方形的四个顶点为 $(0,1),(1,2),(2,1),(1,0)$，转换成切比雪夫后，四个顶点的坐标变成$(1,-1),(3,-1),(3,1),(1,1)$
>
> 此时的正方形是一个边长是原正方形变成的$\sqrt2$被的正着的正方形

void solve() {
    const int N = 3000;
    int f[6004][6004]; memset(f, 0, sizeof(f));

        int x, y, r; cin >> x >> y >> r;
        int nx = (x + y), ny = (x - y + 3000);
