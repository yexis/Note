##### 3 key points

###### 3.1 极角是什么(Polar Angle)？

极角是平面几何中的一个概念，表示一个点相对于某个参考方向的角度；

一般来说，从原点出发，连接某个点形成一个向量，这个向量与$x$轴正方向的夹角，就是极角。



###### 3.2 极角怎么计算

在C++中，使用 $atan2(y, x)$	计算夹角；返回的是弧度，范围是$[-\pi, \pi]$



###### 3.3 按极角排序

极角排序就是将多个点按照它们相对于原点的极角从小到大排列。

例如：

$A(1,0)\ 0^\circ$

$B(1, 1)45^\circ$ 

$C(0, 1)90^\circ$

$D(-1,1)135^\circ$

 排序结果就是$A < B < C < D$

在极角排序中，一般不使用极角角度作为排序规则，因为会存在浮点数精度误差；

**一般推荐使用叉积进行极角排序 ；**

> 叉积公式$a \times b = x_1y_2 - x_2y_1$，当两个向量的夹角小于 $180^\circ$ 时：
>
> - $a\times b>0$：$b$在 $a$ 的逆时针方向。
> - $a\times b<0$：$b$ 在$a$ 的顺时针方向。
> - $a\times b=0$：两个向量共线。

**特别注意：不能直接使用$cross(a,b)$作为全局极角排序的比较函数；因为跨越$180^\circ$时可能不满足严格弱序；一般先按照上、下平面分类，再使用叉积比较**

> 证明：
>
> 设点$A(1,0)$，点$B(-1,-1)$
>
> $A \times B = 1 * -1 - 0 * -1 = -1$ 
>
> 说明$B$在$A$的右侧，但在极角坐标系中，$B$应该在$A$的左侧



###### 3.4 极角排序代码

// 极角排序，此时Point实际是从原点出发的向量
// 上平面: [0 ~ 180)
// 下平面: [180, 360)
template<class T> bool polar_angle_cmp(const Point<T>& a, const Point<T>& b) {
    int updown_a = (a.y > 0 || a.y == 0 && a.x > 0) ? 0 : 1 ;
    int updown_b = (b.y > 0 || b.y == 0 && b.x > 0) ? 0 : 1;
    if (updown_a != updown_b) return updown_a < updown_b;
    return cross(a, b) > 0;
}

template<class T> bool intersect(Line<T> l1, Line<T> l2) {
    Point<T> a = l1.a, b = l1.b;
    Point<T> c = l2.a, d = l2.b;
    
    T cr1 = cross(a, b, c);
    T cr2 = cross(a, b, d);
    T cr3 = cross(c, d, a);
    T cr4 = cross(c, d, b);
    
    // 必须严格异号，排除端点落在线上的情况
    if (cr1 == 0 || cr2 == 0 || cr3 == 0 || cr4 == 0) return false;

    return (cr1 > 0) != (cr2 > 0) && (cr3 > 0) != (cr4 > 0);
}

void solve() {

    vector<Point<ll>> ps;
    for (int i = 0; i < n; i++) {
        int x, y; cin >> x >> y;
        ps.push_back(Point<ll>(x, y));
    }
    sort(ps.begin(), ps.end(), polar_angle_cmp<ll>);

    for (int i = 0; i < n; i++) {
        ps.push_back(ps[i]);
    }

    int ans = 0, r = 0;
    for (int l = 0; l < n; l++) {
        r = max(r, l + 1);
        // 以向量ps[l]为基准时，需要将与向量ps[l]极角差小于180度的向量加入窗口
        while (r < l + n && cross(ps[l], ps[r]) > 0) {
            r++;
        }
        ans = max(ans, r - l);
    }
    cout << ans << "\n";
}
