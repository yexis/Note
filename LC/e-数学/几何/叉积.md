##### 3 key points

叉积的定义：对于两个向量 $\overrightarrow{AB} = (dx, dy)$ 和 $\overrightarrow{CD} = (dx_1, dy_1)$，其叉积公式为$dx * dx_1 - dy * dy_1$，二维叉积的结果是一个标量

 



##### 4 thought

###### 叉积的使用场景

**判断点在直线（向量）的左侧还是右侧**

判断$P(x, y)$在 由点$A(x_1, y_1)$ 和点$B(x_2, y_2)$构成的直线的哪一侧

构造两个向量 

$\overrightarrow{AB} = (x_2 - x_1, y_2 - y_1)$

$\overrightarrow{AP} = (x - x_1, y - y_1)$

叉积 $cross = (x_2 - x_1) * (y - y_1) - (y_2 - y_1) * (x - x_1)$

- $cross > 0$，点$P$位于$\overrightarrow{AB}$的左侧
- $cross < 0$，点$P$位于$\overrightarrow{AB}$的右侧
- $cross = 0$，点$P$与$\overrightarrow{AB}$共线

**前提条件：需要两个向量的夹角小于$180^\circ$，当夹角大于$180^\circ$时，需要分上、下平面进行对比**





**判断两个线段（向量）是否相交**

对于向量$\overrightarrow{AB}$  和 $\overrightarrow{CD}$，要判断它们是否在两条线段内部严格相交

需要满足条件

- 条件1：端点$A、B$必须位于$\overrightarrow{CD}$两侧
- 条件2：端点$C、D$必须位于$\overrightarrow{AB}$两侧 

两个条件同时成立，才能确定两条线段严格相交

// 求叉积：(x, y) 相对于向量 (x2 - x1, y2 - y1)的位置
// 注意 叉积是带方向的线段，计算两个向量的差积
// 叉积 > 0: 从向量a逆时针旋转到向量b，即向量b位于向量a的左侧
// 叉积 > 0: 从向量a顺时针旋转到向量b，即向量b位于向量a的右侧
// 叉积 = 0: 两个向量共线
ll cross(ll x1, ll y1, ll x2, ll y2, ll x, ll y) {
    return 1ll * (x2 - x1) * (y - y1) - 1ll * (y2 - y1) * (x - x1);
}

// 求叉积 (向量a，向量b) 相同起点
// 叉积 > 0: 从向量a逆时针旋转到向量b，即向量b位于向量a的左侧
// 叉积 > 0: 从向量a顺时针旋转到向量b，即向量b位于向量a的右侧
// 叉积 = 0: 两个向量共线
ll cross(ll dx1, ll dy1, ll dx2, ll dy2) {
    return 1ll * dx1 * dy2 - 1ll * dy1 * dx2;
}

template<class T> bool intersect(Line<T> l1, Line<T> l2) {
    Point<T> a = l1.a, b = l1.b;
    Point<T> c = l2.a, d = l2.b;
    
    T cr1 = cross(a, b, c);
    T cr2 = cross(a, b, d);

    if (cr1 == 0 || cr2 == 0 || cr3 == 0 || cr4 == 0) return false;

}
