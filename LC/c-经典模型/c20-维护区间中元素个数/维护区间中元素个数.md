###### 3.1 维护区间中元素出现个数

假设数组$a = [2,4,3,4,4,1,3,2]$，现在存在$q$个询问，分别为询问区间$[l,r]$中$x$出现了多少次

答案：

维护每个元素全局出现的所有下标，然后进行二分；例如对于上述数组，存在一下维护

```cpp
2: [0,7] 
4: [1,3,4]
3: [2,6]
1: [5]
```

对于询问的区间$[l,r]$，只需要使用两次二分即可求得

```cpp
void solve() {
    int n, q; cin >> n >> q;
    vector<int> a(n); for (int& e : a) cin >> e;

    unordered_map<int, vector<int>> pos;
    for (int i = 0; i < n; i++) pos[a[i]].push_back(i); 

    while (q--) {
        int l, r, x; cin >> l >> r >> x;
        int k1 = lower_bound(pos[x].begin(), pos[x].end(), l) - pos[x].begin(); // >= l
        int k2 = upper_bound(pos[x].begin(), pos[x].end(), r) - pos[x].begin() - 1; // <= r 
        int cnt = max(0, k2 - k1 + 1);
        cout << cnt << "\n";
    }
}
```



###### 3.2 判断区间中元素是否恰好出现c次

假设数组$a = [2,4,3,4,4,1,3,2]$，现在存在$q$个询问，分别为询问区间$[l,r]$中$x$是否恰好出现$c$次

答案：

方案一：二分

方案二：对于固定左端点$l$的区间询问，在维护好$pos$之后，只需判断$r$是否位于$pos[x]$的第$c$个下标和第$c+1$个下标之间
