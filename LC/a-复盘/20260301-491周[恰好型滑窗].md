### T4 [3859. 统计包含 K 个不同整数的子数组](https://leetcode.cn/problems/count-subarrays-with-k-distinct-integers/)

##### 1 emphasis

- 恰好型滑动窗口



##### 2 key points

给你一个整数数组 `nums` 和两个整数 `k` 和 `m`。

返回一个整数，表示满足以下条件的 **子数组** 的数量：

- 子数组 **恰好** 包含 `k` 个**不同的** 整数。
- 在子数组中，每个 **不同的** 整数 **至少** 出现 `m` 次。



##### 3 thought

使用恰好型滑动窗口的思路：

最直观的感受是

答案 = 子数组个数（**至少包含k个不同的整数，每个数至少出现m次**） - 子数组个数（**至少包含k+1个不同的整数，每个数至少出现m次**）

这里的**【每个数】**实则蕴含**【恰好】**的意思，明显，不适合使用滑动窗口了

**因为，滑动窗口的前提是：单调性，即越大越满足，或者越大越不满足**



此时，可以将**【恰好】**转成**【至少】**

假设，

答案 = 子数组个数（**至少包含k个不同的整数，至少k个数至少出现m次**） - 子数组个数（**至少包含k+1个不同的整数，至少k+1个数 至少出现m次**）

但是这样真的对吗？是不对的；多出了一部分（至少包含k+1个数，至少k个数 至少出现m次）（至少包含k+2个数，至少k个数 至少出现m次）......



所以，正确的表述应该是

答案 = 子数组个数（**至少包含k个不同的整数，至少k个数至少出现m次**） - 子数组个数（**至少包含k+1个不同的整数，至少k个数 至少出现m次**）



##### 4 code

代码1：滑动右边界

```cpp
class Solution {
public:
    using ll = long long;
    const int N = 100005;
    long long countSubarrays(vector<int>& a, int K, int M) {
        int n = a.size();
        // 计算：至少包含k个不同的整数，至少k个数至少出现m次
        auto cal = [&](int L) -> ll {
            ll ans = 0;
            int cc, good; cc = 0; good = 0;
            vector<int> cnt(N);
            for (int l = 0, r = -1; l < n; l++) {
                while (r < n && (cc < L || good < K) ) {
                    ++r; if (r >= n) break;
                    ++cnt[a[r]];
                    if (cnt[a[r]] == 1) cc++;
                    if (cnt[a[r]] == M) good++;
                } 
                if (cc >= L && good >= K) ans += (n - r);
                --cnt[a[l]];
                if (cnt[a[l]] == 0) cc--;
                if (cnt[a[l]] == M - 1) good--;
            }
            return ans;
        };
        return cal(K) - cal(K + 1);
    }
};
```





代码2：滑动左边界

```cpp
class Solution {
public:
    using ll = long long;
    const int N = 100005;
    long long countSubarrays(vector<int>& a, int K, int M) {
        int n = a.size();
        // 计算：至少包含k个不同的整数，至少k个数至少出现m次
        auto cal = [&](int L) -> ll {
            ll ans = 0;
            int cc, good; cc = 0; good = 0;
            auto check = [&]() -> bool {
                return cc >= L && good >= K;
            };
            vector<int> cnt(N);
            int l = 0, r = 0;
            while (r < n) {
                cnt[a[r]]++;
                if (cnt[a[r]] == 1) cc++;
                if (cnt[a[r]] == M) good++;    
                while (l <= r && check() ) {
                    cnt[a[l]]--;
                    if (cnt[a[l]] == 0) cc--;
                    if (cnt[a[l]] == M - 1) good--;    
                    l++;
                }
                ans += l;
                r++;
            }
            return ans;
        };
        return cal(K) - cal(K + 1);
    }
};

// [1,2,2,1,4,4,3,3]
```
