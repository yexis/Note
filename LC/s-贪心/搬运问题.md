### Title 搬运问题

##### 1 emphasis

- 最小搬运问题

  



##### 2 examples

##### 3 key points

 目标数组 $[1,2,3,4,5]$

当前数组 $[5,4,3,2,1]$，代表不同的石子数量

使用【搬运】操作，使得 当前数组 变成最终数组，每次的搬运的代价为$1$

搬运：移动一个石子到相邻的位置

**求最终搬运的最小代价**



##### 4 thought

###### 结论

令$sumA$表示目标数组的前缀和，$sumB$表示当前数组的前缀和，最小搬运代价为$S$

则 $S = \sum_{i=1}^{n}(sumA_i - sumB_i)$

即两个数组的前缀和中每一项的差的绝对值之和

> 证明：隔板法
>
> 假设相邻元素之间存在一个隔板，然后考虑每个隔板的贡献，即每个隔板被穿过的次数
>
> 例如 $a = [1\  | \ 2 \ | \ 3 \ | \ 4 \ |\  5\ ]$， $b = [\ 5\  | \ 4 \ | \ 3 \ | \ 2 \ |\  1\ ]$
>
> 那么对于每一个位置的前缀和，如果两者不相等，那么说明一定有$delta$个元素会穿过该隔板从左至右，或者从右至左
>
> 累计所以隔板的贡献，即前缀和每一项作差的绝对值之和，得证！

ll power(ll x, ll b, ll m = mod) {
    ll ans = 1;
    while (b) {
        if (b & 1) {
            ans *= x;
            ans %= m;
        }
        x *= x;
        x %= m;
        b >>= 1;
    }
    return ans;
}

void solve() {
    int n; cin >> n;
    vector<int> a(n); for (int i = 0; i < n; i++) cin >> a[i];
    vector<int> prev(n + 1); for (int i = 0; i < n; i++) prev[i + 1] = prev[i] + a[i];

    // 前i个元素 组合和为j的最小成本
    ll dp[n + 1][10001];
    for (int i = 0; i <= n; i++) for (int j = 0; j <= 10000; j++) dp[i][j] = INF;
    dp[0][0] = 0;
    // 思考1: 从小到大枚举d，为什么就能保证最终枚举出来的序列是单调不减的
    // 思考2: 如果题目要求严格单调递增的话，怎么做？（0/1背包）
    for (int d = 0; d <= 100; d++) {
        int x = d * d; // 枚举当前项
        // 如果是0/1背包，这里令g = f
        for (int i = 1; i <= n; i++) {
            for (int j = x; j <= prev[n]; j++) {
                dp[i][j] = min(dp[i][j], dp[i - 1][j - x] + abs(prev[i] - j));
            }
        }
        // 如果是0/1背包，这里将f = g
    }
    if (dp[n][prev[n]] >= INF) {
        cout << -1 << "\n";
        return;
    }
    cout << dp[n][prev[n]] << "\n";
}
