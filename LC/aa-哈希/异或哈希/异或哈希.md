##### 3 key points

把 $x$ 映射成一个 $[0,2^{64} −1]$ 内的随机整数。

由于同一个数异或两次等于$0$，异或偶数次也等于$0$，所以「子数组每个数的频率都是偶数」等价于「子数组的异或和为 $0$」。

这个技巧叫做**异或哈希（XOR hashing）**。

- **计算任意子数组的异或和可以用 [前缀和](https://leetcode.cn/problems/range-sum-query-immutable/solution/qian-zhui-he-ji-qi-kuo-zhan-fu-ti-dan-py-vaar/)。**



使用场景：

**集合问题**

- 判断两个集合是否相同
- 两个子树包含的颜色集合是否相同
- 两条树上路径包含的颜色集合是否相同
- 两个字符串包含的字符集合是否相同



**奇偶性问题**

- 判断两个区间的元素奇偶性（例如：区间异或和为0，说明区间内每个元素出现次数是偶数）
- 区间内所以元素出现次数为奇数的元素集合
- 两个区间的元素奇偶性是否完全相同



**动态集合问题**





##### 4 thought

###### 4.1 单纯的异或哈希会碰到的问题

设数组$a = [6,5,4,8,8]$，数组$b = [1,1,5,6,4]$

只使用异或哈希的话上述两个数组的哈希值是相同的，因为异或会将偶数消元；

因此，在异或哈希的基础上，最好能加上权值和哈希





##### 5 code

###### 5.1 通用模板

```cpp
// ============ 异或哈希 模板开始
struct XorHash {
    using ull = uint64_t;
    static inline unordered_map<int, ull> hash; // 保证全局公用一个hash table
    static inline mt19937_64 rng = 
        mt19937_64(chrono::steady_clock::now().time_since_epoch().count());
    
    int n;
    vector<int> a;
    vector<ull> sum_xor; // 异或哈希
    vector<ull> sum_weight; // 权值哈希
    
    XorHash(vector<int>& aa) {
        a = aa;
        n = a.size();
        sum_xor.resize(n + 1);
        sum_weight.resize(n + 1);
        for (int i = 0; i < n; i++) {
            int x = a[i];
            if (!hash.count(x)) hash[x] = rng();
            sum_xor[i + 1] = sum_xor[i] ^ hash[x];
            sum_weight[i + 1] = sum_weight[i] + hash[x];
        }
    }
    pair<ull, ull> get(int l, int r) {
        return {sum_xor[r + 1] ^ sum_xor[l], sum_weight[r + 1] - sum_weight[l]};
    }
};
// ============ 异或哈希 模板结束
```





###### 5.2 原始模板

```cpp
using ull = uint64_t;
static inline mt19937_64 rng = mt19937_64(chrono::steady_clock::now().time_since_epoch().count());
unordered_map<int, ull> hash;
vector<ull> sum;
void get_xor_hash(vector<int>& a) {
    int n = a.size();
    sum.resize(n + 1);
    for (int i = 0; i < n; i++) {
        int x = a[i];
        if (!hash.count(x)) hash[x] = rng();
        sum[i + 1] = sum[i] ^ hash[x];
    }
}
```
