##### 3 key points

把 $x$ 映射成一个 $[0,2^{64} −1]$ 内的随机整数。

由于同一个数异或两次等于$0$，异或偶数次也等于$0$，所以「子数组每个数的频率都是偶数」等价于「子数组的异或和为 $0$」。

这个技巧叫做**异或哈希（XOR hashing）**。

- **计算任意子数组的异或和可以用 [前缀和](https://leetcode.cn/problems/range-sum-query-immutable/solution/qian-zhui-he-ji-qi-kuo-zhan-fu-ti-dan-py-vaar/)。**



使用场景：

**集合问题**

- 判断两个集合是否相同
- 两个子树包含的颜色集合是否相同
- 两条树上路径包含的颜色集合是否相同
- 两个字符串包含的字符集合是否相同



**奇偶性问题**

- 判断两个区间的元素奇偶性（例如：区间异或和为0，说明区间内每个元素出现次数是偶数）
- 区间内所以元素出现次数为奇数的元素集合
- 两个区间的元素奇偶性是否完全相同

##### 5 code

```cpp
using ull = uint64_t;
static inline mt19937_64 rng = mt19937_64(chrono::steady_clock::now().time_since_epoch().count());
unordered_map<int, ull> hash;
vector<int> sum;
void get_xor_hash(vector<int>& a) {
    int n = a.size();
    sum.resize(n + 1);
    for (int i = 0; i < n; i++) {
        int x = a[i];
        if (!hash.count(x)) hash[x] = rng();
        sum[i + 1] = sum[i] ^ hash[x];
    }
}
```
