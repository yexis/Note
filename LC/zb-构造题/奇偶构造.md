###### 3.1 奇偶性构造（贪心）

要求n个数的和为奇数

1. 先填充一个奇数；

2. 再考虑填充偶数；（两个奇数或者一个偶数，优先考虑两个奇数）

   

要求n个数的和为偶数

1. 先填充一个偶数；（两个奇数或者一个偶数，优先考虑使用两个奇数）

2. 再考虑填充偶数；（两个奇数或者一个偶数，优先考虑使用两个奇数）



###### 3.2 要点

- 要构造出一个奇数：必须使用一个奇数
- 要构造出一个偶数：可以使用两个奇数或者一个偶数



###### 3.3 适用场景

 对于约束条件存在奇偶性的构造题，可以考虑奇偶性构造

ll power(ll x, ll b, ll m = mod) {
    ll ans = 1;
    while (b) {
        if (b & 1) {
            ans *= x;
            ans %= m;
        }
        x *= x;
        x %= m;
        b >>= 1;
    }
    return ans;
}
